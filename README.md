## How To Deploy On Render (Static Website - FREE)

### Option A - Static Site (Recommended, FREE)

1. Go to https://dashboard.render.com
2. Click **New +** → **Static Site**
3. Connect your GitHub → Select repo `kjbtc-mining`
4. Settings:
   - **Name:** `kjbtc-mining`
   - **Branch:** `main`
   - **Build Command:** (leave EMPTY - no build needed)
   - **Publish Directory:** `.`  (dot = root, where index.html is)
5. Click **Create Static Site**
6. Wait 1 min → Your site is live at:
   `https://kjbtc-mining.onrender.com`

### Option B - If Publish Directory Fails

If Render says "Not Found", try:
- Publish Directory: `./`
- Or move `index.html` to root (not in /public folder)
